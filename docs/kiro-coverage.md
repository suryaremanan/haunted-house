## How to read this table

- **Kiro capability** names what Kiro supplied: a requirements-first spec, steering, a correctness property with its property-based test, an agent hook, or a spike recorded in steering.
- **Implementation evidence** and **Test evidence** are paths in this repository. `scripts/check-submission.py` fails if a path written here does not exist.
- **Demo evidence** points at the beat of [demo-script.md](demo-script.md) that shows the feature.
- **Completion** uses five fixed values. "Complete" means the spec tasks are ticked and their tests pass in `scripts/check-release.sh`; it is used only for features that need no running Crew, browser or public site to be shown working. "Tests pass; live Crew check pending" means the code and tests are done but the feature has not yet been run end to end on a real Crew gateway. "In progress", "Pending" and "Not started" mean what they say. A "Pending" row is written and tested locally but depends on a step that has not happened, such as the first Pages run.

The table is reusable: add a row per feature and keep the seven columns.
