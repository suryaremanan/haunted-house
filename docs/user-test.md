# User test

A short, moderated test of the public replay with people who have not used Kiro. It checks whether a stranger can read the house, find what needs them, and make a decision without help. Nothing in the results table below has been filled in yet: every row is for a real session, written down by the person who ran it.

## Who and where

- Five people who have not used Kiro or Crew. Developers and non-developers both count; note which.
- The public replay link, in the participant's own browser, on their own machine. No install.
- One moderator, who reads each task aloud once, starts a timer, and does not help. If the participant asks a question, the moderator answers "What would you try?".
- About 15 minutes per person.

## Before you start

1. Open the public replay in a fresh private window.
2. Say: "This is a page about software agents working on a project. I will give you five small tasks. Think aloud. There are no wrong answers; we are testing the page, not you."
3. Do not explain rooms, ghosts, doors or Kiro.

## Tasks

| # | Task (read aloud) | Done when | Give up after |
|---|---|---|---|
| 1 | "Get into the house." | The participant is inside the recorded mansion | 2 min |
| 2 | "Find out which agent needs you right now, and what it wants." | They name Tinker 2 (or point at it) and say it wants to run a command | 3 min |
| 3 | "Decide what should happen to it, using practice mode." | They refuse or release the held command in practice mode and say what changed | 3 min |
| 4 | "Show me what was finally built." | The "What was made" page is on screen | 3 min |
| 5 | "Turn off the moving effects." | Still House is on, or the Fright setting is Calm | 1 min |

## After the tasks

Ask, and write the answer down as said:

1. "In one sentence, what is this page for?"
2. "Was anything frightening in a way you did not like?"
3. "On a scale of 1 to 5, how sure were you about what each button would do?"
